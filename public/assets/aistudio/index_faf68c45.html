About BinPulse

BinPulse is a smart-city waste monitoring project built to prevent overflowing bins, detect hazardous gas buildup early, and help collection crews prioritize routes using live IoT sensor telemetry.

1. Sensor Capture

Ultrasonic and gas sensors measure bin fill percentage and air quality inside each container.

2. Live Cloud Sync

Readings stream in real time to Firebase Realtime Database under bins/bin1 through bins/bin5.

3. Fill Prediction

BinPulse tracks recent readings to estimate time to full and flags any gas reading above 2500.

4. Priority Dispatch

Crews view hazards first, log pickups with one click, and export CSV operational reports.
